# 수집 자료와 색인

`raw/`에는 공식 원문과 getSpot 원자료, `processed/`에는 정제 문서와 청크 및 별도 형식의 장소 자료, `indexes/`에는 검색 색인을 둔다. 실제 조례·별표의 전처리 본문은 [인계 자료](handoff/jungeun/ordinance-handoff-2026-11-24/)에 있다. 생성한 색인은 Git에서 제외하므로 새 환경에서는 [자료 준비 명령](../README.md#실제-자료-준비와-근거-조회)으로 만든다.

`tests/fixtures/source_manifest.json`은 제공된 문서 목록과 첨부 링크의 검증 표본이다. 조례 본문은 포함하지 않는다. `tests/fixtures/handoff_documents.json`은 데모용 합성 본문이다. 두 입력의 용도와 본문 로더 사용법은 [공통 기반 최소 인계본](../docs/handoff.md)을 따른다.

수집 결과에는 원문 위치와 URL, 발행 주체, 이용 조건, 수집 시각, 확인 상태와 버전을 남긴다. 문서와 장소 자료를 같은 근거로 취급하지 않는다. 동일한 본문도 지역과 출처 연결을 보존한다.

생성 자료는 기본적으로 Git에서 제외한다. 공유 가능한 작은 표본은 `tests/fixtures/`에 두고 합성 여부와 목적을 표시한다. 실제 자료를 제출에 포함할 때는 이용 조건을 검토하고 관리 위치, 버전, 접근 방법과 재생성 절차를 문서로 남긴다.

`scripts.index`는 명시한 공용 문서 JSON을 읽어 로컬 색인 스냅샷을 생성한다. 이 경로의 청킹은 문서 전체를 유지한다. 조례·별표 인계 자료는 `scripts.prepare_data`에서 조문과 표 행 단위로 나눠 색인한다. `eval/`과 `results/`를 문서 입력에 포함하지 않는다. 공통 기준은 [개발 환경과 연결 기준](../docs/TEAM-SETUP.md)을 따른다.
