## 운영 리라이트와 사전의 적용 범위

팀 A 색인으로 실행할 때는 [실행 설정](../../configs/team-a-rewrite-chat.json)의 `rewrite_enabled`로 확장 사전 적용을 선택한다. ON에서는 사전의 방언·외래어·재질 규칙과 품목 별칭을 검색 질의에 적용한다. 실행 기록에 `catalog-rules-v2`과 사용한 카탈로그의 SHA-256을 남긴다. 답변 생성에는 원질문과 해석된 지역·조건을 전달한다.

[팀 A 답변 평가](../evaluation/answer_experiments/answer_evaluation_runtimes.py)의 기존 OFF 구성을 유지하고, 같은 색인과 답변 모델로 두 구성을 실행하는 `create_a_rewrite_comparison`을 제공한다. Streamlit 연결과 재현 명령은 [프로젝트 README](../../README.md#실행-방법)를 따른다.

[모델 리라이트](../../prompts/query/rewrite.md)는 원질문 뒤에 기본 사전의 공식 품목명을 덧붙이는 규칙을 사용한다. 확장 프롬프트 문안은 별도로 검증하고, 모델에 연결할 때 입력과 허용 출력 규칙을 같은 원본으로 관리한다. 우유팩·두유팩·소주팩의 `종이팩` 보강은 확장 사전의 회귀 테스트에서 확인한다.

## 사전을 읽는 형식

- [item_catalog.json](item_catalog.json) 한 파일에 품목, 별칭, 방언·외래어, 장소, 전문 용어와 출처가 들어 있다. `rewrite_rules`에는 언어 치환 순서, 조사·인용문 처리에 필요한 패턴, 재질 약어의 문맥과 예외를 담았다. 정규식은 Python `re` 문법이다.
- `alias_profiles.team`과 `alias_profiles.personal_fork`에는 각각의 `src/query/aliases.py`에서 가져온 별칭표 3개와 55개가 들어 있다. 확장 사전 실행기는 `item_aliases`를 사용한다. 프로필별 표는 대상 검색어와 출처 파일 해시를 보존해 비교할 수 있다.
- [개발용 평가 JSON](rewrite_evaluation.json)에는 품목·표현 54건, 방언 28건, 복합 품목 16건, 개인 검색 검증 22건을 담았다. `datasets[].data.cases`에서 문항을 읽으며, 문항과 기대 결과는 개발용 검증에 사용한다.
- [aliases.py](aliases.py)는 팀의 `src/query/aliases.py`와 같은 `ITEM_ALIASES`와 `normalize_item()` 형식이다. 사전 실행기는 필요한 언어 표현을 정규화한 뒤 검색어를 괄호로 보강한다. `계란껍질은 음식물 쓰레기인가요?`는 `계란껍질은 음식물 쓰레기인가요? (음식물류폐기물) (달걀 껍데기)`가 된다.
- JSON의 `item_aliases`는 같은 별칭표다. `items_by_group`에서 분야의 품목 키를 찾고 `items_by_key`에서 이름과 지역별 출처를 조회할 수 있다. 품목 키는 한글 NFC 정규화, 대소문자 접기, 공백 제거 순으로 계산한다.
- `exact_item_aliases`는 `스타일러`, `마사지기`, `원형 형광등`처럼 품목명 전체가 일치할 때 연결하는 표다. `normalize_item()`에서 사용할 수 있다. 이 규칙으로 `헤어 스타일러`나 `LED 원형형광등`은 문장 안에서 다른 품목의 별칭에 걸리지 않는다.
- 품목별 `sources`는 지역 안내를 연결하는 출처 키, 조문·표 행 또는 안내 안의 위치, 품목이 등장한 분야를 담는다. 크기나 대상이 적힌 경우 해당 출처의 `qualifier`에 남겼다. 예를 들어 송파구 소형가전 안내의 식기세척기는 **1m 미만**으로 기재되어 있다. [송파구 폐가전 안내](https://www.songpa.go.kr/www/contents.do?key=3171)
- `groups`는 품목을 찾기 위한 검색 범위다. 배출 분류와 수거 기준은 해당 지역·규격·품목 상태와 원문을 확인한다. 예를 들어 소형가전 안내의 가스레인지 표기는 송파구 목록과 서대문구 수거함 제외 공지에서 적용 범위가 다르다. [송파구 폐가전 안내](https://www.songpa.go.kr/www/contents.do?key=3171) · [서대문구 수거체계 변경 공지](https://www.sdm.go.kr/news/news/notice.do?mode=view&sdmBoardSeq=309565)
- `sources.kind`에서 두 구의 전처리·공식 안내, 제품명 참고 자료, 주민 검색 표현을 확인할 수 있다. `lookup_context`는 가정용·업소용, 전원, 재질, 철거 여부처럼 품목마다 유지할 검색 조건이다. 관악구 품목표는 나무 판자와 운동용품의 명칭 참고에 사용했다. [관악구 품목표](https://www.gwanak.go.kr/site/gwanak/08/10803020300002016091310.jsp)

## 질문별 프롬프트 입력 초안

[prompt_context.py](prompt_context.py)의 `make_prompt_context_builder()`를 시작할 때 한 번 만든 뒤 질문마다 호출한다. 원질문, 지역 해석에서 확정한 구·동, 일치한 별칭과 해당 품목·장소의 확인 조건을 JSON으로 돌려준다. `--district`와 `--dong`을 생략하면 해석된 지역 필드는 `null`이다.

```zsh
uv run --locked python -m src.rewrite_dictionary.prompt_context \
  "잠실동에서 종이 뽁뽁이랑 LED전구 소켓은 우야노?" \
  --district 송파구 --dong 잠실동
```

예시에서는 `종이 완충재`와 `LED 전구 소켓`을 보강하고, 포장재의 재질과 등기구 본체 포함 여부를 확인할 수 있다. `농약 공병`처럼 내용물이 불확실한 표현은 확인 항목을 전달한다. 새 품목별 조건 26개와 모호한 표현 20개는 [prompt_vocabulary.json](prompt_vocabulary.json)에서 관리한다.

[프롬프트 문안](prompt_instructions.md)은 `catalog-context-v2` 입력을 사용하는 연결 전 초안이다. 입력은 질문에 해당하는 표현과 조건으로 제한한다. 질문 등장 순서로 별칭 8개, 품목 6개, 명시 상태 8개, 장소 3개, 모호 표현 4개, 각 품목·장소의 조건 4개를 담는다. 상한을 넘으면 `omitted_counts`에 필드별 생략 수를 남긴다. 사용자 질문은 그대로 보존하고 매칭에 NFC 표기를 쓴다.

`item_mentions`는 품목 표현에 직접 연결된 상태를 담는다. 예를 들어 `안 씻은 우유팩`과
`씻은 두유팩`은 표준 검색어가 모두 `종이팩`이어도 상태를 각각 보존한다.
`스티로품`, `족빨뼈`는 확인한 오탈자 별칭으로 추가했다. `스타일러`와 `헤어 스타일러`는
기존처럼 구분한다.

`스치로폼이랑 족발뼈 중 스티로폼만 어디 버려?`처럼 배출할 품목이 분명한 단순 질문은
선택한 품목의 검색어를 보강한다. `스치로폼만 먼저 버리고 나머지는 어디에 내놓나요?`처럼
뒤에서 나머지 품목도 묻거나 선택 범위가 불명확하면 열거한 품목과 검색어를 보존한다. 스치로폼·스티로폼, 페트병·패트병, 유리병·유리벵, 족발뼈·족빨뼈처럼
확인한 표기 차이를 선택에 반영한다. 투명 페트병과 일반 페트병, 깨진 유리병과 유리병,
족발뼈와 돼지뼈처럼 조건이나 품목 범위가 다르면 구분한다. 목록이 질문
첫머리나 확인된 구·동 표기 직후에 있으면 검색 문장에서도 목록을 걷어낸다.
동만 제시한 질문은 팀 지역 해석 결과에서 동을 확인한 뒤 목록을 줄인다.
앞부분에 날짜나 상태 등 다른 조건이 있으면 목록을 포함한 문장을 보존한다.
실제 검색 전후는 같은 색인과 설정에서 품목별 근거 순위, 제외 품목 노출,
원질문의 상태 보존으로 비교한다.

후속 모델 연동에서 `serialize_prompt_context()`로 만든 JSON을 시스템 지시문과 분리된 사용자 입력으로 전달한다. 연결 테스트에서 어댑터가 직렬화 결과를 그대로 전달하는지 검증한다.

## 전국 방언, 외래어와 일본어계 생활어

[방언 사전](dialect_dictionary.json)에 수도권(경기·강화), 충청, 전라, 경상, 강원, 제주와 공통 구어의 **표현 83개**를 담았다. 품목 JSON의 `dialect`에서도 같은 자료를 읽을 수 있다. 권역은 용례의 출처이며 배출 지역은 원질문과 지역 해석 결과를 따른다.

| 출처 권역 | 리라이트 예시 |
| --- | --- |
| 수도권(경기·강화) | 비우구 → 비우고, 가져가이꺄 → 가져가나요, 겨란 → 계란 |
| 충청 | 워떻게·워치게 → 어떻게, 버리는 겨 → 버리나요 |
| 전라 | 어쩧게 → 어떻게, 없응께 → 없으니까 |
| 경상 | 우야꼬 → 어떻게 해야 하나요, 찌짐 → 부침개 |
| 강원 | 씻그고 → 씻고, 우유팩 아이 씻고 버려도 → 우유팩 안 씻고 버려도 |
| 제주 | 어떵 허는고 → 어떻게 하나요, 지슬 → 감자 |
| 공통 구어 | 어케 버려 → 어떻게 버려, 테레비 → 텔레비전 |

`정구지 → 부추`처럼 여러 권역의 용례가 확인되면 해당 출처를 함께 기록했다. `솔`, `소코리`처럼 단독으로 뜻을 가리기 어려운 표현은 문맥 확인 항목에 담았다. [국립국어원 지역어 듣기](https://www.korean.go.kr/front/page/pageView.do?page_id=P000054) · [국립국어원 일상 대화 보고서](https://www.korean.go.kr/front/reportData/reportDataView.do?mn_id=207&pageIndex=1&report_seq=1220&searchOrder=) · [제주특별자치도 구술 자료](https://www.jeju.go.kr/jedu/map/record.htm?page=23)

[외래어 사전](loanword_dictionary.json)에 `laptop charger → 노트북 충전기`, `LED bulb cover → LED 전구 커버`, `후라이팬 → 프라이팬`, `다라이 → 대야` 등 **표현 118개**를 담았다. 품목 JSON에서는 `loanwords`로 읽는다. 일본어계 항목에는 광복 이후 순화 자료에 나온 표현을 포함했다. 개별 표현의 유입 시기는 확인된 자료 범위에서만 다룬다. [국립국어원 일본어 투 용어 순화 자료집](https://www.korean.go.kr/common/download.do?c_file_name=894c27ab-14f9-4707-95ee-81f1be60899c_0.pdf&file_path=reportData) · [국립국어원 외래어 표기 자료](https://www.korean.go.kr/nkview/nknews/200212/53_15.html)

[runtime.py](runtime.py)는 JSON에서 방언·외래어·재질 규칙과 기본 별칭을 읽는다. 팀 `create_runtime`의 `rewriter` 인자로 `make_catalog_rewriter()`를 넘기면 지역 해석 후 검색 문자열을 다듬고, 파이프라인이 원질문과 구·동을 보존한다. 검증은 팀 파이프라인에서 이 콜백을 선택하고 모의 검색·응답을 붙여 진행했다. 팀 색인 실행과 비교에서 확장 사전을 선택 적용한다.

```zsh
uv run --locked python -m src.rewrite_dictionary.runtime "잠실동에서 계란껍질은 워떻게 버려?"
```

## 장소별 폐기물 검색

## 전문 용어와 재질 표기

JSON의 `technical_lookup.terms_by_key`에서 전문 용어 63개의 뜻과 관련 검색어를, `technical_lookup.material_codes`에서 재질 표기 26개의 명칭과 확인 조건을 찾을 수 있다.

| 주민 표현 또는 표기 | 함께 검색할 용어 |
| --- | --- |
| 플라스틱 용기 | 합성수지 용기 |
| 비닐 포장재 | 비닐(필름)류 |
| 발포 플라스틱 포장재 | 발포합성수지 포장재 |
| PP 뚜껑 | 폴리프로필렌 |
| 뚜껑: HDPE / 라벨: PP | 고밀도 폴리에틸렌, 폴리프로필렌 |
| ABS 수지 | 아크릴로니트릴-부타디엔-스티렌 공중합체 |
| PVDC 랩 | 폴리염화비닐리덴 |
| PLA 컵 | 폴리젖산 |
| EPS 완충재 | 발포폴리스티렌 |
| 코팅된 MDF 선반 | 중밀도섬유판 |
| OTHER 표시 | 기타 재질 표시 |

합성수지에는 용기·트레이, 필름·시트, 발포 포장재 등 여러 형태가 있다. `OTHER`에는 표시 목록에 없는 단일재질과 일부 혼합·복합재질이 모두 포함된다. `PET-G`와 `PET`, `PC 재질`과 `PC 본체`를 구분한다. [한국환경공단 분리배출표시제도](https://www.keco.or.kr/web/lay1/S1T183C1049/contents.do) · [재활용법령 포장재 명칭](https://www.law.go.kr/DRF/flDownload.do?flSeq=161063347)

목재·공사, 금속·전지·조명, 사업장·실험·농업, 수거 안내 용어도 포함했다. 예를 들어 `폐목재`에는 공사에서 나온 것인지와 재질 상태를, `리튬이차전지`에는 충전식 전지 종류를, `납부필증`에는 수수료 납부 표기를 함께 확인한다.

[technical_terms.py](technical_terms.py)의 재질 확장기는 재질 문맥에 있는 약어의 뜻을 검색문에 붙인다. `PBS`, `PBSA`, `PBAT`, `PBT`, `POM`과 `PC`, `ABS`는 명시적 재질 문맥이 필요하다. `PC 본체`는 컴퓨터 품목으로 남고, `자동차 ABS 표시등`은 원래 표현을 유지한다. [식품용 기구 및 용기·포장 공전](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=&flSeq=141486339) · [한국환경공단 일괄표시 예시](https://www.keco.or.kr/group01/lay1/S296T497C509/contents.do)

## 출처와 재생성

[공식 자료 검토본](official_source_snapshot.json)은 `review_only`로 표시하며, 출처 8건의 메타데이터와 로컬 검토 기록 18건을 담는다. [검토 모듈](official_review.py)의 `review_district_records(item, district)`는 이 스냅샷에서 해당 구의 기록을 찾는다. 검색 카탈로그 빌드와 프롬프트 실행은 검토 스냅샷을 읽지 않는다. 답변 근거나 인용은 팀 검색 결과를 사용한다.

검토 자료에서 확인한 재질명 17개와 공식 품목 조회 API 인증 상태는 검토본의 `material_names`와 `pending.wasteguide_get_item`에서 확인한다. 검색에 쓰는 명칭은 `prompt_vocabulary.json`의 품목명과 [전문 용어 사전](technical_terms.py)의 표기를 따른다. [식약처 제2026-72호](https://www.mfds.go.kr/brd/m_211/view.do?seq=14991) · [공공데이터포털 API 명세](https://www.data.go.kr/data/15156866/openapi.do?recommendDataYn=Y)

팀 저장소 `dev`의 `c04cb70`에 있는 `data/handoff/jungeun/ordinance-handoff-2026-11-24/`를 기준으로 했다. 대형폐기물 표의 품목 셀은 서대문구 111개와 송파구 147개를 읽고, 규격 칸에서 확인한 일부 세부 품목도 포함했다. 서로 같은 표기에서 공백과 대소문자만 달라지는 경우 한 품목 키로 묶고, 각 지역 원문 위치를 모두 보존했다.

음식물 세부 품목과 소형가전 종류에는 구청 안내 링크를 별도 자료로 남겼다. JSON의 `sources`에서 전처리 파일과 구청 안내를 구별할 수 있다. [서대문구 음식물쓰레기 문답](https://www.sdm.go.kr/fileUpload/board/92/20260601_15855869764698833.pdf) · [송파구 음식물쓰레기 안내](https://www.songpa.go.kr/www/contents.do?key=3161) · [서대문구 소형폐가전 안내](https://www.sdm.go.kr/civil/type/metal.do?sdmBoardSeq=301238) · [송파구 폐가전 안내](https://www.songpa.go.kr/www/contents.do?key=3171)

실험실 약품은 명칭·성분과 용기 잔류 여부를 유지하며 소속 기관의 연구실 안내를 조회한다. 농약은 남은 내용물과 빈 포장을 구분한다. 송파구의 2026년 10월 폐농약 공지는 해당 기간의 자료로 기록했다. [중앙대학교 연구실 폐기물 안내](https://safety.cau.ac.kr/contents.php?mid=m01_11) · [정부민원안내콜센터 남은 농약 안내](https://www.110.go.kr/data/counselView.do?num=C04_664043) · [한국환경공단 영농폐기물 안내](https://www.keco.or.kr/web/lay1/S1T185C1072/contents.do)

품목·별칭을 수정할 때는 [aliases.py](aliases.py), [prompt_vocabulary.json](prompt_vocabulary.json) 등 생성 원본을 고친 뒤 카탈로그를 재생성한다. 별칭표 스냅샷과 평가 입력을 갱신할 때는 별도로 아래 명령을 사용한다.

```zsh
uv run --locked python -m src.rewrite_dictionary.export_rewrite_inputs "/path/to/team-repo" "/path/to/personal-fork"
```

저장소의 생성 결과를 덮어쓰지 않고 비교하려면 프로젝트 루트에서 임시 파일에 출력한다. 빌더는 인계 번들의 전처리 파일을 매니페스트 해시와 대조하고 UTF-8, LF 줄바꿈으로 결과를 쓴다. `cmp`가 출력 없이 종료 상태 0을 반환하면 파일이 일치한다. 생성 원본의 변경을 반영할 때는 같은 명령에서 `--output`을 생략한다.

```zsh
catalog_tmp=$(mktemp)
uv run --locked python -m src.rewrite_dictionary.build_item_catalog \
  data/handoff/jungeun/ordinance-handoff-2026-11-24 --output "$catalog_tmp"
cmp src/rewrite_dictionary/item_catalog.json "$catalog_tmp"
rm -f "$catalog_tmp"
```

프로젝트 루트에서 `uv run --locked python -m pytest tests/unit/query`로 질의 모듈을 검증한다. CI에서도 카탈로그 생성 명령을 임시 경로에 실행하고, 추적 중인 JSON과 바이트 단위로 비교한다. 사전 코드와 테스트는 팀 CI의 Ruff, mypy, 문법 검사와 테스트·커버리지 범위에 포함된다.
