# 실험 전용 문항

개발셋(`eval/dev.json`, 10문항)과 최종셋(`eval/test.json`, 20문항)과 **섞지 않는** 실험용 문항이다.

- `songpa-table-dev.json` (+ `songpa-table-dev-grading.json`): 송파구 시행규칙 별표 표 행 14문항. 최종 평가에서 C가 놓친 유형(글자 사이가 벌어진 품목명, 품목명이 없는 행, 동 이름 나열 표)을 개선하는 임베딩 입력 실험에 쓴다. 최종셋·개발셋·`screen_check_set`과 허용 근거 청크가 겹치지 않는다.
- **주의: `exp-sp-bangi-weekday`와 `exp-sp-wirye-apt-time`은 정답 근거가 검색 제외 대상(송파구 시행규칙 별표 4 동별 배출 요일표, `EXCLUDED_SOURCES`)이라 어떤 구성도 찾을 수 없다.** 실험 결과에서 도달 가능한 12문항만 개선 효과를 판단한다(`report.md` 8장).
- 허용 근거는 필수 사실이 모두 들어 있는 송파구 청크 전부다(같은 품목이 여러 행에 반복된다). 사람의 대조는 아직 하지 않았다.
- 실험 계획과 규칙은 `report.md`의 "개선 시도"와 작업일지를 따른다. 최종셋으로 튜닝하지 않는다.
