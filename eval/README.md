# 평가셋

개발용 `dev.json`과 최종용 `test.json`을 이 폴더에서 별도로 관리한다. 현재 실제 문항 파일은 없다. 문항 수, 구성과 채점 기준은 [문제와 평가 기준](../docs/problem.md)을 따른다.

개발문항 초안은 답변 생성과 품질 추적 담당자(강성수), 최종셋 관리는 화면과 관찰 검증 담당자(이승주), 원문 근거 교차 확인은 데이터 수집과 질문 정제 담당자(이정은)가 맡는다.

문항에는 질문 식별자, 질문과 조건, 답변 가능 여부, 필수 사실, 허용 근거와 원문 위치 및 판정 이유를 연결한다. 세부 필드 형식은 공통 실행기와 맞춘다. 최종셋은 준비하는 시점부터 개발과 튜닝에 사용하지 않는다.

정답표와 허용 근거 목록은 채점에만 사용하고 검색 색인, 생성과 질문 다듬기 입력에 전달하지 않는다. 정답을 뒷받침하는 원문 문서는 정상적으로 색인한다. 청킹을 바꾸면 근거 매핑을 갱신한다.
