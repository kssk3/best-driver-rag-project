# 정오표 (공식 최종셋을 바꾸지 않는 정정)

`eval/test.json`(최종 20문항)은 2026-11-26 공식 실행 전에 고정했고 **그대로 둔다.** 실행 뒤 문항 결함이 확인되면 여기에 정정판을 따로 두고, 공식 결과(`results/final-*`)는 바꾸지 않은 채 정정판 결과를 보조 표로 추가한다.

- `test-v07-corrected.json` (+ `-grading.json`): 공식 `test-v07-sd-food-container-apartment`의 정정판. 원래 문항은 서대문구 시행규칙 별표 4의 음식물류 전용용기 납부필증 행(공동주택 120ℓ, 1,080)을 "가격"으로 물었는데, 그 열은 "판매이윤"(표 앞 문단도 "…납부필증 판매이윤")이고 시행규칙 제5조 제1항은 가격을 수집·운반수수료, 반입수수료, 판매이윤, 제작비의 합으로 정의한다. 정정판은 판매이윤을 직접 묻는다. 허용 근거 청크는 같다.
- `test-v06-reclassified.json` (+ `-grading.json`): 공식 `test-v06-sp-ogeum-weekday`를 답변 가능에서 **근거 없음으로 재분류**한 정오표. 정답 근거(송파구 시행규칙 별표 4 동별 배출 요일표)가 `EXCLUDED_SOURCES` 때문에 검색에서 제외돼 있어 어떤 구성도 찾을 수 없고, 공식 실행에서 네 구성 모두 `insufficient_evidence`로 안내했다(의도된 동작). 이 오류는 PR #48 리뷰(Codex)가 지적했고 `src/retrieval/search.py`를 대조해 확인했다. 질문은 그대로이고 기대 상태만 바뀐다. 새로 실행하지 않고 공식 실행 결과를 재분류해 센다.
- `v07` 결함은 PR #48 리뷰(Codex)가 지적했고 조문 대조로 확인했다. 정정판 실행 결과와 두 정오표를 모두 반영한 보조 수치는 `report.md` 7.4절, 원본은 `results/errata-v07-2026-11-27/`에 있다.
- `test-d10-corrected.json` (+ `-grading.json`): 공식 `test-d10-sp-reusable-bag`의 정정판. 원래 질문 "만들어 파나요?"는 현재 제작·판매 여부를 묻는 듯하지만 허용 근거는 "구청장은 제작할 수 있고 판매방법 개선과 고객 홍보를 추진해야 한다"는 조례 문장뿐이라 어긋났다. 공식 B·C 답변이 "실제 판매는 확인되지 않는다"고 한정하며 홍보를 빠뜨려 정답 충족 0을 받았다. PR #48 리뷰(Codex)가 지적했고 인정한다. 정정판은 "송파구 조례는 재사용 종량제봉투의 제작과 판매에 대해 무엇을 정하고 있나요?"로 조례 내용을 묻는다. 허용 근거 청크·필수 사실은 같다. 결과는 `results/errata-d10-2026-11-27/`, 수치는 `report.md` 7.4절.
- 2026-11-27에 최종 20문항의 질문·필수 사실·허용 근거를 모델 호출 없이 한 번에 대조했고(질문이 묻는 것과 근거가 말하는 것의 일치, 검색 제외 대상 여부, 근거 없음 3문항의 용어 부재 재확인) 위 3건 외 추가 결함은 찾지 못했다. 사람이 원문과 대조한 것은 아니다.
