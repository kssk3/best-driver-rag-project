# 시연 질문 목록

발표와 시연 영상에서 보여 줄 질문과 기대하는 응답이다. 기대 응답은 최종 20문항 공식 실행(2026-11-26, C 구성, [결과](../results/final-abc-2026-11-26/))에서 나온 답변이다. 모델 응답은 호출마다 조금 달라질 수 있으므로 표현은 같지 않을 수 있고, 핵심 사실(금액, 시간, 장소)이 같은지를 본다.

## 준비

```sh
uv run --locked --env-file .env python -m scripts.run_chat
```

색인이 없으면 먼저 만든다(임베딩 호출). 화면은 C 재정렬과 질문 다듬기 설정으로 뜬다. 지역은 화면에서 질문과 같은 자치구를 고른다. 시연 전에 [데이터 이용과 보안 점검](data-usage.md)의 외부 모델 전송 범위를 확인한다.

## 1. 정상 답변 (출처와 함께)

| 지역 | 질문 | 기대하는 핵심 | 보여 줄 것 |
| --- | --- | --- | --- |
| 송파구 | 송파구 사업장용 일반규격봉투 20리터는 얼마인가요? | 800원 | 표 행에서 값을 찾는 경우, 인용 카드의 원문 위치 |
| 서대문구 | 서대문구에서 이사 가게 돼서 쓰레기봉투를 현금으로 바꾸려면 어디로 가야 하나요? | 동일한 규격봉투를 판매하는 봉투판매소에서 판매가격으로 교환 | 조문 인용(제34조), 질문이 생활어여도 찾음 |
| 서대문구 | 서대문구에서 형광등은 어떻게 배출해야 하나요? | 깨지지 않게 주요 거점 수거함 또는 지정된 수거일·장소에 배출 | 별표 2 인용 |

## 2. 조건·구별 (같은 질문, 다른 자치구)

| 지역 | 질문 | 기대하는 핵심 |
| --- | --- | --- |
| 서대문구 | 서대문구에서 10킬로그램 넘는 세탁기를 버리려면 수수료가 얼마예요? | 5,000원 |
| 서대문구 | 서대문구에서 400리터 냉장고를 대형폐기물로 내놓으면 얼마를 내나요? | 300ℓ 이상 500ℓ 미만 구간이라 10,000원 |

송파구에서 같은 세탁기 질문은 4,000원이 정답이지만 **이번 실행에서 C도 찾지 못했다**(아래 4장). 구별 시연은 서대문구 질문으로 한다.

## 3. 근거 없음 (무리하게 답하지 않음)

| 지역 | 질문 | 기대하는 응답 |
| --- | --- | --- |
| 서대문구 | 서대문구 대형폐기물 수거를 신청하려면 콜센터 전화번호가 뭐예요? | "현재 확인한 자료로는 답변하기 어렵습니다." (정보 부족 상태) |
| 송파구 | 송파구에서 대형폐기물을 모바일 앱으로 신청할 수 있나요? | 같은 정보 부족 안내 |

문서에 번호나 앱 신청 방법이 없어 지어내지 않고 안내하는 것이 목적이다.

## 5. 질문 다듬기 (최적화)

최종 20문항 중 5문항에서 검색어가 바뀌었다(품목 사전의 별칭이 덧붙는다). 예를 들어 "서대문구에서 우유팩은 어떻게 배출하나요?"는 검색어가 "서대문구에서 우유팩은 어떻게 배출하나요? (종이팩)"로 바뀐다. 이 20문항에서는 검색 순위와 정답 충족에 이득이나 손해가 구별되지 않았다. 실행 기록(`runs.csv`)에 원질문(`original_question`)과 변환 질의(`search_query`)가 함께 저장되므로 시연은 이 기록을 보여 주는 정도로 한다. 비교 수치는 [보고서 7장](../report.md)에 있다.
