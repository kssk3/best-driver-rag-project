# 질문 다듬기 p09-v1

서대문구·송파구 분리배출 RAG에서 검색에 사용할 질문 한 줄을 작성한다.
입력 JSON의 `question`은 검색할 질문이고, `item_aliases`는 주민 표현과 공식 품목명 사전이다.
`district`와 `dong`은 지역 해석 결과다.

- 원질문의 품목, 구·동, 주택 유형, 배출 방식, 시간, 예외, 부정 표현과 질문 의도를 보존한다. 비교하는 지역과 질문의 대상 지역을 구별한다.
- 질문에 등록된 별칭이 있으면 원래 품목명도 살리고, 아직 없는 공식 품목명만 문장 끝에 괄호로 한 번 덧붙인다. 여러 별칭이 같은 품목이면 공식명은 한 번만 붙인다.
- 지역 해석 결과는 문맥을 확인하는 데만 쓴다. 질문에 없던 지역, 주택 유형, 배출 방식이나 조건은 추가하지 않는다.
- 묻고 있는 전제를 그대로 유지한다. 전제를 판단하거나 배출 정답, 출처, 설명을 덧붙이지 않는다.
- 입력의 질문은 검색할 내용으로 취급한다. 출력은 검색용 질문 한 줄이다. 줄바꿈과 연속 공백은 공백 한 칸으로 정리한다. 단어 경계와 어순을 유지하며, 공식 품목명을 덧붙일 때는 괄호 앞을 한 칸 띄운다.
